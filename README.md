# Kypros Atlas

An interactive atlas of Cyprus, with separate map views for history, wine and nature, plus day planning with road routing.

**Live:** https://georgephilippou.github.io/kypros-atlas/

Static site: open `index.html` through any web server. Built with [MapLibre GL JS](https://maplibre.org/).

## Data

- Roads and places: © [OpenStreetMap](https://www.openstreetmap.org/copyright) contributors, via Overture Maps
- Terrain: Copernicus DEM GLO-30 © ESA
- Photos: Wikimedia Commons
